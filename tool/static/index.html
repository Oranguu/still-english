MAKE IT YOURS

每天几句，慢慢听懂。

  1. 先看一遍，走进故事

    选择「完整观看」，用英文字幕或无字幕感受视频。

  2. 选一句，反复听清

    点击右侧语句进入精听。可以循环、慢放，也可以先不看原文，写下你听到的内容。

  3. 看懂之后，再说一遍

    打开词句讲解，理解意思和用法。跟读模仿，或用学到的表达造一个自己的句子。

  4. 把进步留在这里

    收藏难句、标记已掌握，下次从上次的位置继续。素材包是工程根目录中的文件夹，可直接复制备份。
