# Still · 慢慢听

完整安装说明、功能介绍和素材包格式见 [项目 README](../README.md)。

在项目根目录安装并启动：

```sh
python3 tool/setup.py
tool/.venv/bin/python tool/launcher.py
```

需要 Python 3.10+，推荐 3.12。macOS 也可以依次双击本目录的 `安装依赖.command` 和 `启动.command`。

第一次使用时素材库为空。自行准备的素材包统一保存在项目根目录的 `source/`；摘录和收藏句子的复习卡位于根目录的 `review/`；个人进度、日志及精讲升级备份位于本目录的 `.state/`，本机依赖位于 `.venv/`。这些文件不属于公开源码。旧版根目录的素材包会在新版启动时迁移，原有进度保留。

复习卡默认折叠，只显示英文，点击后展开。可以按单词、短语、句子筛选，摘录的分类可手动调整。视频收藏自动同步到复习库；取消收藏后卡片隐藏，再次收藏会恢复原笔记和复习记录。

复习库还提供「听力复习」：先听来源原声，再揭晓文字，按听懂程度安排下次练习。在视频中可以标记听不懂的原因。听力记录独立保存在 `review/listening/`，不改变原有卡片的掌握状态，也不额外使用 AI 用量。

AI 讲解需要用户自己的 Codex CLI 和 ChatGPT 登录，使用自己的 Codex 用量。已有素材包可离线学习。

新素材和缺失讲解默认生成简单版，已有讲解保留。需要更细的解释时，在当前句点击「升级这一句精讲」，只升级选中的一句。

v1.7 起，新下载、本地原音识别和手动导入字幕都会减少零碎精听片段：4 个英文词以内的短句先尝试与后一句合并，再尝试并入前一句；纯语气词和简短应答同样处理。合并要求间隔不超过 1.5 秒，总时长不超过 13 秒，总词数不超过 40 个。仍然过短或只有语气词的内容保留在完整字幕中，不单独出题，也不为它单独生成 AI 讲解。整理规则不调用 AI，简单讲解和按需精讲的默认设置不变。已有完整素材包不会因更新软件或重复导入而自动重切。

长视频有至少 120 句待制作的简单讲解时，最多同时处理 4 批，每批完成即保存。中断后只补做缺失部分；取消任务会停止所有在处理的批次。

分享源码请使用 GitHub Download ZIP 或根目录 README 中的导出方法，不要直接压缩包含个人数据的工作目录。

素材库支持分类、多个标签、排序和精听片段的中英文搜索。点击卡片「整理」自定义分类和标签；多个标签取交集，命中的内容可以直接跳转精听。仅保留在完整字幕中的短句不单独参与检索。自动建议基于标题、来源和时长，不额外使用 AI。手动设置保存在私有的 `tool/.state/catalog/`，不会改动素材和学习记录；迁移个人资料时一并备份该目录。

在「新建素材包 → 本地视频」选择或拖入英文电影、课程和访谈，也可制作学习素材包。先安装本地语音转写组件，工具会保留原视频，从原音识别英文，不自动使用随附字幕。长视频按段保存，失败或中断后点击重试可续做。
