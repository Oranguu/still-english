MAKE IT YOURS

每天几句，慢慢听懂。

  1. 先看一遍，走进故事

    选择「完整观看」，用英文字幕或无字幕感受视频。

  2. 选一句，反复听清

    点击右侧语句进入精听。可以循环、慢放，也可以先不看原文，写下你听到的内容。

  3. 从小词开始，慢慢弄明白

    打开词句讲解，看看基础单词、常用短语和句子拆解。旧讲解可以点击「升级这一句精讲」，使用自己的 Codex 用量获得更细的解释。

  4. 划下来，常常再见

    用鼠标或长按划选讲解中的文字，点击「保存到复习库」。不方便划选时，也能用每条讲解下方的保存按钮。视频里收藏的句子也会进入复习库。卡片先只显示英语，点开再看讲解、记笔记；还可以按单词、短语、句子筛选，逐个标记掌握。

  5. 把进步留在这里

    进度自动保存，下次从上次的位置继续。素材包在工程的 source 文件夹，复习摘录在 review 文件夹，可分别复制备份；这些都是你的本地学习资料。
