MAKE IT YOURS

每天几句，慢慢听懂。

素材多了，可以用分类、标签和搜索来找。点击卡片「整理」添加自己的分类与标签；搜索也会查找中英文字幕，点击命中的原句即可开始精听。自动整理不消耗 AI 用量。

  1. 让本地视频成为教材

    在「新建素材包 → 本地视频」选择电影、访谈或课程，也可以拖入一个视频。工具保留原文件，在本地从英文原声重新识别字幕，再按选择生成简单讲解。随附的字幕不会自动使用。

  2. 先看一遍，走进故事

    选择「完整观看」，用英文字幕或无字幕感受视频。

  3. 选一句，反复听清

    点击右侧语句进入精听。可以循环、慢放，也可以先不看原文，写下你听到的内容。

  4. 从小词开始，慢慢弄明白

    新素材先生成简单讲解，看看翻译和重点词句。需要更细的解释时，点击「升级这一句精讲」，使用自己的 Codex 用量补充基础单词、短语和句子拆解；其他句子保持原样。

  5. 划下来，常常再见

    用鼠标或长按划选讲解中的文字，点击「保存到复习库」。不方便划选时，也能用每条讲解下方的保存按钮。视频里收藏的句子也会进入复习库。卡片先只显示英语，点开再看讲解、记笔记；还可以按单词、短语、句子筛选，逐个标记掌握。

  6. 用耳朵，再认识一次

    在学习时点击「这句没听懂」，标记卡住的原因。进入「我的复习库 → 听力复习」，先听来源整句原声，再按需要看英文、中文或慢听。完整听过后记录感受；看过提示或慢听过，这次就不会记为独立听懂。工具会安排下次练习时间，不会额外调用 AI。

  7. 把进步留在这里

    进度自动保存，下次从上次的位置继续。素材包在工程的 source 文件夹，复习摘录在 review 文件夹，可分别复制备份；这些都是你的本地学习资料。
